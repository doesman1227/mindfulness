# MindShift ／ マインドフルネスを学びなおすノート

マインドフルネス瞑想・ACT・セルフアクセプタンスについて、**専門家ではない個人が自分で調べたことを整理した学習用のまとめ**サイトです。静的HTML／CSS／JavaScriptのみで作られています（ビルド不要）。

## 構成

- **マインドフルネスとは** (`index.html`) — 定義／なぜ求められるか／得られる効果／誤解と真実／5つの要素
- **実践方法** (`methods.html` ＋ `practice-*.html`) — タイミング・シチュエーション別（落ち着いた時間に／日常のすき間に／その場で立て直す／習慣にする）の全11手法＋28日間チャレンジ
- **コラム** (`column*.html`) — ACT・研究データ・自己受容・トラブル対処、心理療法（SIY/ACT/DBT/CBT）、セルフアウェアネス、連載「ブッダの教え×マインドフルネス（全4回）」
- **共通** (`assets/style.css`, `assets/site.js`) — 全ページ共通のデザインと、ナビ・フッターの自動挿入

## 見る

`index.html` をブラウザで開くだけで表示できます。
